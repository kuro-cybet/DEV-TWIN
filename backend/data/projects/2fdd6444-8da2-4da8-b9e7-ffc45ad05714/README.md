# Smart Renewable Energy Grid Dashboard Mock

Software-only prototype for the Software Engineering assessment. Hardware is simulated; no physical sensors, PLCs, batteries, generators or SCADA equipment are required.

Run locally by opening `index.html`, or with Docker:

`docker compose up --build`

Then open `http://localhost:8080`.

The dashboard demonstrates simulated generation, demand, battery state, asset status, alerts, forecasting and the proposed software data flow.
